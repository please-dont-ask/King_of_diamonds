# King_of_diamonds_WIP
Mathematical logic game based on Alice in borderland

King of diamonds is undoubtedly my favorite game in AIB in terms of mechanics, so i thought it'd be fun to try and figure out a way to code it's system, epecially considering the incremental rules. of course that's not much of a game if you make all your own guesses, so i had to make some bots too. It was a very fun challenge to try and figure out each character's individual logic model. To not make it too extensive, i set up an initial goal of coding them so that they will play the game identically to their manga counterpart so long as you play like Chishiya does and i'm satisfied enough with the result at the moment. The models aren't techinically finished just yet, each character only has the logic applied up until the time the time they survive, but that's something i'll work on later

i tried to keep hardcoding to minimum, otherwise it wouldn't be fun, the main thing that is hardcoded is their initial guesses, since with no prior input there is no reason for them to pick differently, and random choices onto the canon result. if you want an overview of character's inital logic: Kuzuryu picks the average between the winning guess and 0, shaving a bit off the top as the numbers get too low, Asuma does similarly except he fails to adjust correctly and will deafault to 0 once this average gets under 4, Benzo calculates the average between two layers of logic he thinks are plausible for others to pick and multiplies by 0.8, Daimon picks the average of her own guess and 0 and then adjusts slighly

i added a txt file with Chishiya's guesses if anyone wants to test, i'll probably add an automatic fill option soon, if you play freely with the bots it is very possible to run into code errors as this is still a work in progress on that front. If anyone actually sees this and plays my little ""game"" i will be very honored, please tell me if you find any bugs so i can fix them for my  next version. if just want to text the rules system you can play a free range version, should have less bugs but i haven't checked it in a bit so who knows, also let me know if it's fucked over. i might eventually make this into a visual novel style game, if i have the patience for something like that

thank you if you read until the end, this is my first real semi-finished coding project and i really love this series, so i'm really excited about it!
